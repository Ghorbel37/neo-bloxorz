## Neo Bloxorz 1.3.4: vibration the Carreau way

- Vibration now uses the same calls as the Carreau app (the plugin's `impact` and
  `notification` haptics), which your phone does play. The plain one-shot vibration used in
  1.3.2–1.3.3 did nothing on it.
  - wall bump and switch: medium impact
  - fall: heavy impact
  - level solved: success pattern
  - heart lost / time up: error pattern
- **Settings › Test vibration** now plays 4 kinds of vibration one after another, numbered on
  screen, then lists them: tell me which numbers you felt if anything is still off.

### Install
Download `neo-bloxorz-v1.3.4-debug.apk` below and open it. 1.3.3 and later are signed with the
same key, so this installs over 1.3.3 and keeps your progress (no uninstall needed).
